#     python -m pip install -r requirements.txt
#     python -m pip install -e .
#     python -m general_k.environment --check-packages
#
# The last line verifies the numerically relevant package versions while
# allowing a different Python or operating-system environment. Use the stricter
# `--check` mode to report Python, package, OS, and architecture drift together.
#
# Results are deterministic given the seeds documented in README.md;
# floating-point summation order can differ across BLAS builds, so expect
# agreement to many significant figures rather than bitwise identity on a
# different platform. Transitive plotting and test dependencies are resolved by
# pip and do not enter the paper's numerical estimates.
